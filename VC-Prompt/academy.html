프롬프트 마스터로 성장하기 위한 훈련소

섹션 A. 탐색과 메타인지 (Discovery)
1

역방향 프롬프팅 실전 +

내가 무엇을 모르는지조차 모를 때, AI에게 역으로 질문 리스트를 제안받는 훈련입니다.

💡 공식 템플릿

나는 [상황/목표]를 해결하려고 해. 네가 최고의 결과물을 내기 위해 나에게 필요한 질문 5가지를 역으로 해줘.

🔥 실전 예시

"프롬프트 컨벤션 개념을 처음 기획하는데 어디서부터 시작할지 모르겠어. 나한테 질문을 던져줘."

2

12대 키워드 도출: 형태와 해부 +

대상의 구조와 상하위 계층을 완벽하게 파악하기 위한 뼈대 도출 실습입니다.

💡 공식 템플릿

[분석 대상]의 전체 구조를 트리 다이어그램 형태로 시각화하고, 각 계층별 핵심 구성 요소를 리스트업 해줘.
섹션 B. 프레임워크 주입 (Frameworks)
3

생각의 캔버스(4요소) 작성법 +

목적, 대상, 제약, 형식의 4요소 프레임워크로 완벽히 구조화하는 실습입니다.

💡 공식 템플릿

- 목적(Objective): [무엇을 달성할 것인가]
- 대상(Audience): [누가 읽을 것인가]
- 제약(Constraints): [글자수, 금지어, 말투]
- 형식(Format): [마크다운, 표, 리스트]
4

CREATE 공식 심화 +

Context, Request, Explanation, Action, Tone, Extras로 세밀한 논리를 구축합니다.

💡 공식 템플릿

# Context (맥락): [배경 설명]
# Request (요청): [핵심 요구사항]
# Explanation (설명): [부연 설명]
# Action (행동): [구체적 스텝]
# Tone (어조): [톤앤매너]
# Extras (제약): [제외할 사항]
5

XML 태그 구조화 실습 +

지시어와 데이터를 명확히 분리하여 환각(Hallucination)을 완벽히 방어합니다.

💡 공식 템플릿

<instruction>
다음 제공된 context만을 바탕으로 분석해 줘.
</instruction>

<context>
[참조할 텍스트나 데이터 입력]
</context>
섹션 C. 고급 추론 기법 (Advanced)
6

페르소나 (Persona) 완벽 빙의법 +

AI에게 특정 직업과 경력, 성향을 주입하여 답변의 깊이를 비약적으로 상승시킵니다.

💡 공식 템플릿

당신은 [경력 15년 차의 수석 시스템 아키텍트]입니다. [안정성과 확장성을 최우선으로 고려하는 성향]을 가졌습니다. 이 관점에서 다음 문제를 해결해 주세요.
7

생각의 사슬 (CoT) 유도법 +

"단계별로 생각하라"는 제약 조건을 걸어 AI가 숨겨진 논리적 오류를 스스로 찾아내게 합니다.

💡 공식 템플릿

이 문제를 해결하기 위해, 1) 원인 분석 2) 대안 탐색 3) 최종 결론의 순서로 단계별로 차근차근 생각하여(Step-by-step) 도출해 주세요.
Phase 1. 단일 프롬프트 튜닝 (Tuning)

완벽한 '한 방' 만들기 +

단일 프롬프트 템플릿 내에서 4대 프레임워크와 페르소나, 제약 조건을 조합하여 한 번의 대화로 최적의 답을 끌어내는 과정을 훈련합니다.

🎯 핵심 실습 (Action Item)

역할(Role), 지시(Task), 형식(Format), 제약(Constraints)을 결합한 500자 분량의 '단일 슈퍼 프롬프트'를 직접 작성하고 결과를 테스트합니다.

Phase 2. 체이닝 (Chaining)

분할 정복의 예술 +

단일 프롬프트로는 해결할 수 없는 거대한 업무를 Step 1, Step 2, Step 3으로 쪼개어(분할 정복) 파이프라인을 설계하는 시스템 아키텍처 과정입니다.

🎯 핵심 실습 (Action Item)

Step 1: 입력된 문서에서 핵심 키워드 5개만 추출해.
Step 2: 추출된 키워드를 바탕으로 각각 1줄 요약을 작성해.
Step 3: 최종 결과를 HTML 테이블로 포맷팅해.
Phase 3. 라우팅 (Routing)

의도 기반 동적 분기 시스템 +

사용자의 질문 의도(번역, 요약, 코드 작성 등)를 먼저 판별한 뒤, 그에 가장 최적화된 전문가(Expert) 프롬프트 템플릿으로 분기시켜 응답을 생성하는 고급 구조를 배웁니다.

🎯 핵심 실습 (Action Item)

Classifier(분류기) 프롬프트를 작성하여 입력값을 A, B, C 유형으로 나누는 프롬프트를 실습합니다.

Phase 4. 자체 교정 (Evaluator)

품질을 검증하는 평가자 루프 +

생성자(Generator) AI가 만든 결과물을 다른 프롬프트(Evaluator)가 비판하고 평가하여, 통과 기준에 미달할 경우 스스로 피드백을 반영해 재작성하게 만드는 검증 루프입니다.

🎯 핵심 실습 (Action Item)

너는 엄격한 평가자야. 위에서 생성된 글을 '가독성', '정확성' 2가지 기준으로 10점 만점으로 평가하고, 8점 미만인 경우 구체적인 수정 지침을 반환해.
Phase 5. 자율 에이전트 (Agentic ReAct)

궁극의 자율성 +

목표(Goal)만 주어지면 AI가 스스로 생각(Thought)하고, 필요한 외부 도구(Action)를 검색 및 사용하여 관찰(Observation)한 뒤 최종 답안을 내놓는 에이전트 설계 최종 과정입니다.

🎯 핵심 실습 (Action Item)

ReAct (Reasoning and Acting) 프롬프트 구조화 및 시스템 프롬프트 작성 실습.

실전 프로젝트: 네이버 블로그 자동화
1
Step 1. 탐색 (Discovery)

트렌드 및 키워드 추출 +

주제를 던지면 현재 트렌드에 맞는 세부 검색 키워드 5개를 뽑아내는 프롬프트 설계

🎯 미션 목표

12대 탐색 키워드 중 '흐름'과 '변수'를 활용하여, 사람들이 많이 검색하는 롱테일 키워드를 발굴하세요.

💡 권장 프롬프트 예시

현재 네이버에서 [특정 주제]와 관련하여 사람들의 검색 '흐름'과 '변수(계절/이슈 등)'를 분석하고, 조회수가 높을 것으로 예상되는 롱테일 키워드 5개를 추출해줘.
2
Step 2. 기획 (Planning)

뼈대(Outline)와 제목 어그로 +

클릭을 유도하는 후킹(Hooking) 제목 3개와 서론-본론-결론의 목차 뼈대를 잡는 프롬프트

🎯 미션 목표

생각의 캔버스 4요소(목적, 대상, 제약, 형식)와 RTF 공식을 사용하여 블로그 기획안을 도출하세요.

💡 권장 프롬프트 예시

- Role: 전문 블로그 기획자
- Task: 앞서 추출한 키워드를 바탕으로 클릭률이 높은 제목 후보 3개와 본문 개요(서론-본론-결론) 작성
- Format: 마크다운 리스트 형식
3
Step 3. 본문 생성 (Generation)

SEO 및 페르소나 빙의 +

파워블로거 페르소나를 주입하여, 네이버 SEO에 최적화된 본문을 작성하는 프롬프트 체이닝

🎯 미션 목표

단순한 정보 전달이 아닌, 실제 사람이 쓴 것 같은 문체와 톤앤매너를 주입하세요.

💡 권장 프롬프트 예시

당신은 월 방문자 10만 명을 기록하는 뷰티/IT 파워블로거입니다. 친근하지만 전문적인 말투('~해요', '~랍니다')를 사용하며, Step 2의 개요를 바탕으로 1,500자 분량의 본문을 작성해 주세요.
4
Step 4. 검증 (Evaluation)

평가자 자체 교정 루프 +

작성된 본문에 금지어(어뷰징 단어)가 있는지 AI가 스스로 평가하고 재작성하는 루프

🎯 미션 목표

Evaluator(평가자) 프롬프트를 설계하여 네이버 봇이 싫어하는 패턴을 제거하세요.

💡 권장 프롬프트 예시

너는 네이버 블로그 검색 품질 검수 봇이야. 작성된 본문 내에 과도한 키워드 반복, 어색한 번역투, 스팸성 단어가 있는지 검사하고, 발견되면 해당 부분을 자연스럽게 수정해서 다시 반환해.
5
Step 5. 출력 (Formatting)

최종 마크다운/HTML 포맷팅 +

블로그 에디터에 바로 복사/붙여넣기 할 수 있도록 출력 형식을 강제하는 프롬프트

🎯 미션 목표

XML 태그 구조화를 사용하여 결과물의 퀄리티를 유지하며 포맷팅을 고정하세요.

💡 권장 프롬프트 예시

최종 결과물은 다음 규칙에 따라 포맷팅해 줘:
<rules>
- 소제목은 반드시 <h2> 태그 또는 ## 로 강조할 것
- 본문 중간에 [이미지 삽입 위치]라는 플레이스홀더를 3곳 배치할 것
</rules>
