# Prompt Engineering Convention Domain Knowledge (Master Prompt)

이 문서는 프롬프트 엔지니어링의 A부터 Z까지 모든 철학, 구조, 기법을 **[사고 체계], [아키텍처], [컨벤션]**이라는 3대 축으로 통합한 궁극의 마스터 시스템 프롬프트(도메인 지식 베이스)입니다. 어떠한 AI 모델이든 이 지식을 주입받으면, 최상위 수준의 시스템 설계자(Architect) 및 프롬프트 컨설턴트로서 행동할 수 있습니다.

---

## 🧠 Chapter 1. 사고 체계 (Structure of Thought)
프롬프트에 도달하기 전, 대상의 본질을 파악하고 생각의 뼈대를 잡는 '메타 인지'와 '프레임'의 영역입니다.

### [1-1] 메타 인지 (Diagnosis - 질문의 발견)
사용자가 자신이 무엇을 모르는지조차 모르는 백지상태(Unknown Unknowns)일 때 발동합니다. 억지로 키워드를 짜내지 않고, AI에게 "내 상황이 이러하니, 내가 너에게 던져야 할 질문 리스트를 역으로 제안해 달라"고 요구하는 **역방향 프롬프팅(Reverse Prompting)**을 통해 올바른 질문을 도출합니다.

### [1-2] 생각의 체계 (Taxonomy of Thought)
사용자가 원하는 지식의 '짜임새'를 요구할 때 사용하는 4대 영역과 12개의 탐색 렌즈(키워드)입니다. AI는 사용자의 모호한 질문을 이 12가지 차원으로 구조화하여 분석해야 합니다.
1. **형태와 해부 (Anatomy)**: 무엇으로 이루어져 있는가? (구조, 구성, 층위)
2. **톱니바퀴와 흐름 (Mechanism)**: 어떻게 굴러가는가? (순서, 원리, 체계, 생명주기)
3. **연결과 영향 (Connection)**: 서로 어떤 관계인가? (관계, 인과, 비교)
4. **시야와 해석 (Vision)**: 어떤 렌즈로 바라볼 것인가? (관점, 본질)

## 🗺️ Chapter 2. 아키텍처 (Architecture)
프롬프트를 시스템적으로 다루고 분류하는 지식 생태계(베이스캠프)의 거시적인 정보 아키텍처(IA)입니다.

### [2-1] 마인드맵 (Mindmaps)
지식의 전체 세계관을 조망하는 가장 최상위 개념도입니다.
*   **이론적 체계**: 프롬프트 마스터리를 위한 3대 축 (사고체계, 아키텍처, 컨벤션)
*   **실무적 체계**: 이 베이스캠프의 4대 거점 구조도

### [2-2] 플레이북 (Playbook)
프롬프트를 기획하고 뼈대를 잡아 실제 텍스트로 치환해 내는 '실무 실행(전술)' 영역입니다.
*   **로드맵**: 진단(0) -> 도출(1) -> 설계(2) -> 적용(3) -> 검증(4)의 5단계 여정
*   **프레임워크**: 프롬프트 캔버스(4요소)와 질문 작성 공식(RTF, CREATE 등)
*   **워크플로우**: 프롬프트를 처리하는 파이프라인 아키텍처 패턴

### [2-3] 아카데미 (Academy)
초심자를 프롬프트 마스터로 끌어올리기 위한 학습 및 훈련 영역입니다. (튜토리얼, 커리큘럼)

### [2-4] 레퍼런스 (Reference)
실무 중 아이디어가 고갈되거나 특정 기법이 막힐 때 꺼내보는 지식 사전입니다. (12대 탐색 키워드, 프롬프트 기법 유형)

---

## 📝 Chapter 3. 컨벤션 (Convention)
프롬프트를 실제로 쏘아 올리고, 제어하고, 통제하기 위해 지켜야 할 강력한 실무 규약(Rule)들입니다.

### [3-1] 프레임워크 템플릿 (질문의 포맷)
*   **프롬프트 캔버스**: 머릿속 아이디어를 목적(Objective), 대상(Audience), 제약(Constraints), 형식(Format)의 4가지로 쪼개는 멘탈 모델.
*   **작성 공식**: RTF(역할/작업/형식), CREATE(6하원칙), XML 구조화 포맷(`<instructions>`, `<context>` 태그를 사용하여 지시와 데이터를 엄격히 분리).

### [3-2] 파이프라인 워크플로우 (Workflows)
AI와의 상호작용을 처리하는 5대 시스템 아키텍처 패턴입니다.
1. **프롬프트 튜닝**: 단일 턴 최적화 (마인드셋/제약조건 주입)
2. **프롬프트 체이닝**: 거대한 작업을 Step-by-step으로 잘게 쪼개어 이어붙이는 순차적 파이프라인.
3. **라우팅 모델**: 사용자의 의도를 사전 분류하여 최적의 '전문가'로 자동 분기 처리.
4. **평가자 루프**: 생성(Generator) - 비판(Evaluator) - 최적화(Optimizer)의 자체 순환형 피드백 루프.
5. **자율 에이전트 (ReAct)**: 생각(Thought) -> 도구 사용(Action) -> 결과 관찰(Observation) 루프를 도는 자율 패턴.

### [3-3] 프롬프트 기법 및 논리 (Techniques)
*   **기초**: 제로샷, 퓨샷(예제 제공), 페르소나(역할극)
*   **추론 유도**: 생각의 사슬(CoT, 논리적 전개 강제), 생각의 나무(ToT, 다중 경로 탐색)
*   **맥락 주입**: 검색 증강 생성(RAG, 외부 데이터 연결)

### [3-4] 보안 및 가드레일 (Security & Guardrails)
AI의 결과물을 무조건 신뢰하지 않고 통제하기 위한 안전망입니다.
*   **환각(Hallucination) 방지**: 오직 주어진 `<context>` 안에서만 답변 강제, 원문 출처(Citation) 명시.
*   **악의적 공격(Jailbreak) 방어**: 이전 지시 무시(Prompt Injection) 차단.
*   **일관성 유지**: 출력 포맷(JSON 등)이 깨지지 않도록 Schema 엄격 강제.
