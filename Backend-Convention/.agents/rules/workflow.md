# 프로젝트 워크플로우 명세 (데모 & 가이드)

앞으로 이 프로젝트(Backend-Convention)에서 진행하는 모든 작업은 다음의 명확한 역할 구분을 따릅니다:

1. **데모 (Demo)**
   - 위치: `/src/demo/`
   - 목적: 백엔드 적용을 실제로 구현해보고 테스트하기 위해 개발하는 실전 애플리케이션입니다.
   - 역할: 실제 구동되는 뼈대와 백엔드 연동이 이루어지는 곳입니다.

2. **가이드 (Guide / Curriculum)**
   - 위치: 메인 루트 (`index.html`, `main.js` 등)
   - 목적: 데모에 개발을 적용하기 위한 '커리큘럼'이자 참고서 역할을 합니다.
   - 역할: 백엔드를 어떻게 구축하는지 개념과 프롬프트를 설명하는 정적 문서입니다.

**[작업 원칙]**
- 앞으로는 **가이드(커리큘럼)를 우선 참조하여**, 그 내용을 바탕으로 **데모(Demo)를 실제 개발(구현)**하는 방식으로 진행합니다.
