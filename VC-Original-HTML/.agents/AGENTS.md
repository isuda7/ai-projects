# Project Rules

## 공통 UI 컴포넌트 내 유틸리티 클래스 사용 규칙
프론트에서 실제로 사용되는 공통 UI 컴포넌트의 내부(마크업 뼈대 및 디자인)에는 Bootstrap이나 Tailwind 스타일의 유틸리티 클래스(`mt-`, `d-flex`, `w-100` 등) 사용을 엄격히 금지하며, 순수 시맨틱(독립) 클래스만을 활용해 SCSS로 제어해야 합니다.
단, 다음과 같은 경우 예외적으로 유틸리티 클래스를 사용할 수 있습니다:
1. 컴포넌트 자체의 본질적인 디자인 요소가 아닌, 외부에서 주입되는 비공통적인 레이아웃 조정 목적일 때
2. 시맨틱 클래스를 억지로 만들 경우 오히려 CSS 구조와 작업의 복잡성을 과도하게 야기하는 1회성 마진/패딩 조정일 때
