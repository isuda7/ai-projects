Bullet List (글머리 기호)

항목을 나열할 때 사용하는 리스트 스타일 컴포넌트입니다. 점, 숫자, 커스텀 아이콘 등 다양한 형태를 지원합니다.

1. Overview & Specs

ClassDescription
.list_bullet기본 점(Disc) 형태의 리스트 (ul 권장)
.list_number숫자 형태의 리스트 (ol 권장)
.list_check체크마크(SVG) 아이콘이 적용된 리스트
.list_unstyled기호와 여백이 모두 제거된 기본 컨테이너 리스트

2. Basic Usage

2.1. Basic Bullet (기본 기호)

  • 디자인 시스템 구축 가이드라인
  • 프론트엔드 아키텍처 설계
    • 컴포넌트 폴더 구조
    • SCSS 네이밍 규칙
  • 접근성 및 시맨틱 마크업 검토
<ul class="list_bullet">
  <li>항목 1</li>
  <li>항목 2
    <ul class="list_bullet">
      <li>중첩 항목</li>
    </ul>
  </li>
</ul>

2.2. Numbered (순서형)

  1. 저장소 클론 받기
  2. 패키지 의존성 설치 (`npm install`)
  3. 로컬 개발 서버 실행 (`npm start`)
<ol class="list_number">
  <li>저장소 클론 받기</li>
  <li>패키지 의존성 설치</li>
  <li>로컬 개발 서버 실행</li>
</ol>

3. Variants & States

3.1. Checkmark (체크 리스트)

  • 반응형 레이아웃 작업 완료
  • 다크모드 토큰 연동 완료
  • 웹 접근성(a11y) 기준 통과
<ul class="list_check">
  <li>반응형 레이아웃 작업 완료</li>
  <li>다크모드 토큰 연동 완료</li>
</ul>

3.2. Unstyled (스타일 없음)

  • 순수 텍스트 항목 1
  • 순수 텍스트 항목 2
  • 순수 텍스트 항목 3
<ul class="list_unstyled">
  <li>순수 텍스트 항목 1</li>
  <li>순수 텍스트 항목 2</li>
</ul>
