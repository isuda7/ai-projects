Radio

사용자가 여러 개의 옵션 중 단 하나만을 선택해야 할 때 사용하는 폼 컴포넌트입니다.

1. Overview & Specs

라디오 컴포넌트의 구성 요소와 클래스 사용법입니다.

Class Description
.radio_wrapper라디오버튼과 라벨을 묶어주는 래퍼 (클릭 영역 확장 및 Flex 정렬)
.radio_input실제 <input type="radio"> 요소 (기본 스타일 제거 후 커스텀 적용)
.radio_label라디오버튼 우측에 표시되는 텍스트 라벨

2. Basic Usage

2.1. Primary State

라벨과 함께 사용되는 기본 라디오버튼 그룹입니다.

<label class="radio_wrapper">
  <input type="radio" name="group" class="radio_input" checked>
  <span class="radio_label">옵션 A</span>
</label>
<label class="radio_wrapper">
  <input type="radio" name="group" class="radio_input">
  <span class="radio_label">옵션 B</span>
</label>
