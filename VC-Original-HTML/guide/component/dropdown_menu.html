Dropdown Menu (드롭다운)

버튼이나 요소를 클릭했을 때 액션 목록을 펼쳐서 보여주는 오버레이 메뉴입니다.

1. Overview & Specs

ClassDescription
.dropdown드롭다운을 감싸는 최상위 래퍼 (Relative)
.dropdown-menu실제 펼쳐지는 메뉴 박스 (Absolute)
.dropdown-item메뉴의 개별 항목 (클릭 가능)
.dropdown-divider메뉴 항목 사이의 가로 구분선
data-bs-toggle="dropdown"트리거 버튼에 부착하여 Bootstrap JS와 연동

2. Basic Usage

2.1. Primary State

  • 프로필 설정
  • 계정 관리
  • 로그아웃
<div class="dropdown">
  <button class="btn outline md dropdown-toggle" type="button" data-bs-toggle="dropdown">
    옵션 선택
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">프로필 설정</a></li>
    <li><a class="dropdown-item" href="#">계정 관리</a></li>
    <li><hr class="dropdown-divider"></li>
    <li><a class="dropdown-item danger" href="#">로그아웃</a></li>
  </ul>
</div>
