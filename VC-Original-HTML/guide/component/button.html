Button

사용자의 이벤트를 받아 액션을 트리거하는 가장 기본적이고 범용적인 상호작용 컴포넌트입니다.

1. Overview & Specs

버튼 컴포넌트의 핵심 클래스와 기본 사용법입니다.

Class Description
.btn버튼 공통 뼈대 (필수 적용)
.primary, .secondary의미적(Semantic) 테마 색상 지정
.is_success, .is_error, .is_warning, .is_info상태(Status) 색상 클래스 지정
.outline배경 없이 테두리만 있는 외곽선 스타일
.ghost배경과 테두리가 모두 없는 투명 텍스트 버튼 스타일
.text텍스트 전용 버튼 스타일 (패딩 최소화)
.sm, .md, .lg, .icon물리적인 크기 및 형태 지정 (기본 사이즈는 md)
.is_loading상태 클래스: 로딩 스피너 애니메이션 활성화 (텍스트 감춤)
.full_width유틸리티: 부모 요소의 100% 너비 차지
Guideline: <button> 태그에는 접근성을 위해 항상 type="button" 또는 type="submit"을 명시해야 합니다.
