Button

사용자의 이벤트를 받아 액션을 트리거하는 가장 기본적이고 범용적인 상호작용 컴포넌트입니다.

1. Overview & Specs

버튼 컴포넌트의 핵심 클래스와 기본 사용법입니다.

Class Description
.btn버튼 공통 뼈대 (필수 적용)
.btn_primary의미적(Semantic) 메인 색상 적용 (기본 버튼 형태)
.variant_outline배경 없이 테두리만 있는 스타일
.variant_ghost배경과 테두리 모두 없는 투명 텍스트 버튼 스타일
.color_danger위험/경고 액션 (적색)
.size_sm, .size_md, .size_lg물리적인 버튼 크기 지정 (기본은 md)
.is_loading로딩 스피너 애니메이션 활성화 (텍스트 감춤)
.full_width부모 요소의 100% 너비 차지
Guideline: <button> 태그에는 접근성을 위해 항상 type="button" 또는 type="submit"을 명시해야 합니다.
