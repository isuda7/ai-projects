Alert

사용자의 주의를 끌기 위해 중요한 정보나 피드백(성공, 경고, 에러)을 표시하는 컴포넌트입니다.

1. Overview & Specs

Class Description
.alertAlert 공통 뼈대 (필수 적용)
.alert_default기본 알림 (회색조)
.alert_primary정보 알림 (파란색)
.alert_success성공 피드백 (녹색)
.alert_danger오류/경고 (적색)
.alert_warning주의 (노란색)
.alert_title알림 메시지의 굵은 타이틀

2. Basic Usage

2.1. Default State

제목과 설명이 포함된 기본 알림창입니다.

알림

새로운 시스템 업데이트가 예정되어 있습니다.

<div class="alert alert_default">
  <div class="alert_title">알림</div>
  <p class="alert_desc">새로운 시스템 업데이트가 예정되어 있습니다.</p>
</div>
