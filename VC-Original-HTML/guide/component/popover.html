Popover (팝오버)

버튼을 클릭했을 때 더 자세한 정보나 입력 폼을 제공하는 미니 다이얼로그 패널입니다.

1. Overview & Specs

AttributeDescription
data-bs-toggle="popover" data-bs-trigger="focus"팝오버 활성화를 위한 필수 속성
data-bs-title="..."팝오버의 제목 (Header 영역)
data-bs-content="..."팝오버의 본문 (Body 영역)
data-bs-trigger="focus"바깥(바닥) 영역 클릭 시 팝오버를 닫기 위한 설정 (기본 권장)

2. Basic Usage

2.1. Default State (클릭 트리거)

<button type="button" class="btn primary md" 
  data-bs-toggle="popover" data-bs-trigger="focus" 
  data-bs-title="결제 상태 확인" 
  data-bs-content="현재 모든 결제가 정상적으로 승인되었습니다.">
  상태 확인하기
</button>

3. Variants & States

3.1. Placements (방향 설정)

<button type="button" class="btn outline md" data-bs-toggle="popover" data-bs-trigger="focus" data-bs-placement="top" data-bs-content="Top popover">
  Top
</button>
