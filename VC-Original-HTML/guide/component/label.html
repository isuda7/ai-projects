Label (폼 라벨)

입력 폼 필드의 제목이나 설명을 나타내는 라벨 컴포넌트입니다.

1. Overview & Specs

ClassDescription
.form_label라벨 기본 스타일
.required필수 입력 항목 표시 (빨간 별표)
.disabled비활성화 시 흐려지는 스타일

2. Basic Usage

2.1. Primary State

<label class="form_label" for="email">이메일 주소</label>
<input type="email" id="email" class="input_field" placeholder="example@email.com">

3. Variants & States

3.1. Required (필수값)

<label class="form_label required" for="password">비밀번호</label>
<input type="password" id="password" class="input_field">

3.2. Disabled (비활성)

<label class="form_label disabled" for="disabled_input">비활성 필드</label>
<input type="text" id="disabled_input" class="input_field" disabled>
