Tooltip (툴팁)

요소에 마우스를 올리거나 포커스를 맞출 때 나타나는 간단한 정보 제공 말풍선입니다.

1. Overview & Specs

AttributeDescription
data-bs-toggle="tooltip"툴팁을 활성화하기 위한 필수 속성
data-bs-placement="top|right|bottom|left"툴팁이 나타날 방향 설정
data-bs-title="..."툴팁 내부에 표시될 텍스트
data-bs-show="always"툴팁을 항상 띄워둔 상태로 고정하는 커스텀 속성

2. Basic Usage

2.1. Placements (방향 설정)

<button type="button" class="btn outline md" data-bs-toggle="tooltip" data-bs-placement="top" data-bs-title="Tooltip on top">
  Tooltip on top
</button>

2.2. Always Visible (항상 띄워두기)

가이드 문서 등에서 툴팁을 항시 띄워두어야 할 때 사용합니다.

<button type="button" class="btn primary md" 
  data-bs-toggle="tooltip" 
  data-bs-placement="top" 
  data-bs-title="항상 노출되는 툴팁" 
  data-bs-show="always">
  고정 툴팁
</button>
