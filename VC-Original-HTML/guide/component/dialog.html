Dialog (Modal)

사용자의 현재 작업을 잠시 중단시키고, 즉각적인 응답이나 확인을 요구하는 오버레이 팝업 컴포넌트입니다.

1. Overview & Specs

Bootstrap Modal JS를 활용하여 작동하며, 시각적인 부분만 커스텀 스타일을 적용합니다.

Class / Attribute Description
.modal, .modal-dialog, .modal-content모달 레이아웃을 구성하는 필수 계층 구조
.modal-header, .modal-body, .modal-footer모달 내부의 영역 분리 클래스
data-bs-toggle="modal"모달을 띄우는 트리거 버튼에 추가하는 속성
data-bs-target="#id"연결할 모달의 ID 지정
data-bs-dismiss="modal"모달을 닫는 버튼(X 버튼, 취소 버튼 등)에 추가

2. Basic Usage

2.1. Primary State

트리거 버튼을 클릭하여 다이얼로그를 띄워보세요.

결제 취소 확인

정말로 결제를 취소하시겠습니까? 이 작업은 되돌릴 수 없습니다.

<!-- Button trigger -->
<button type="button" class="btn primary md" data-bs-toggle="modal" data-bs-target="#myModal">
  모달 열기
</button>

<!-- Modal structure -->
<div class="modal fade" id="myModal" tabindex="-1" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">제목</h5>
      </div>
      <div class="modal-body">본문 내용</div>
      <div class="modal-footer">
        <button type="button" class="btn primary md" data-bs-dismiss="modal">닫기</button>
      </div>
    </div>
  </div>
</div>
