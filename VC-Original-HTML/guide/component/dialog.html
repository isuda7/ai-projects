Dialog (Modal)

사용자의 현재 작업을 잠시 중단시키고, 즉각적인 응답이나 확인을 요구하는 오버레이 팝업 컴포넌트입니다.

1. Overview & Specs

Bootstrap Modal JS를 활용하여 작동하며, 투박한 테두리를 없애고 프리미엄 룩(Shadow, Radius)을 적용한 커스텀 스타일입니다.

Class / Attribute Description
.modal, .modal-dialog, .modal-content모달 레이아웃을 구성하는 필수 계층 구조
.modal-alert-ios아이폰 스타일의 좁고 중앙 정렬된 알럿 팝업 변형 (modal-dialog에 적용)
data-bs-toggle="modal"모달을 띄우는 트리거 버튼에 추가하는 속성
data-bs-target="#id"연결할 모달의 ID 지정
data-bs-dismiss="modal"모달을 닫는 버튼(X 버튼, 취소 버튼 등)에 추가

2. Variants & States

2.1. Basic (기본 팝업)

데이터 삭제 확인

해당 프로젝트에 연결된 모든 파일과 데이터가 영구적으로 삭제됩니다. 계속하시겠습니까? 
<!-- Trigger Button -->
<button class="btn primary md" data-bs-toggle="modal" data-bs-target="#modalBasic">Open Basic</button>

<!-- Modal HTML -->
<div class="modal fade" id="modalBasic" tabindex="-1" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h3 class="modal-title">데이터 삭제 확인</h3>
        <button type="button" class="modal-close-btn" data-bs-dismiss="modal" aria-label="Close">
          <svg xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24" stroke="currentColor" stroke-width="2">
            <path stroke-linecap="round" stroke-linejoin="round" d="M6 18L18 6M6 6l12 12" />
          </svg>
        </button>
      </div>
      <div class="modal-body">해당 프로젝트에 연결된 모든 파일과 데이터가 영구적으로 삭제됩니다. 계속하시겠습니까?</div>
      <div class="modal-footer">
        <button type="button" class="btn outline md" data-bs-dismiss="modal">취소</button>
        <button type="button" class="btn danger md" data-bs-dismiss="modal">삭제하기</button>
      </div>
    </div>
  </div>
</div>

2.2. Alert Dialog (Danger 모달)

프로젝트 삭제

이 작업은 되돌릴 수 없습니다.
정말로 삭제하시겠습니까? 
<!-- modal-dialog 에 modal-alert-ios 클래스 추가 -->
<div class="modal fade" id="modalAlertIos" tabindex="-1" aria-hidden="true" data-bs-backdrop="static" data-bs-keyboard="false">
  <div class="modal-dialog modal-alert-ios">
    <div class="modal-content">
      <div class="modal-header">
        <h3 class="modal-title">프로젝트 삭제</h3>
      </div>
      <div class="modal-body">
        이 작업은 되돌릴 수 없습니다.<br>정말로 삭제하시겠습니까?
      </div>
      <div class="modal-footer">
        <button type="button" class="btn" data-bs-dismiss="modal">취소</button>
        <button type="button" class="btn danger fw-bold" data-bs-dismiss="modal">삭제</button>
      </div>
    </div>
  </div>
</div>

2.3. Form Dialog (입력 폼 포함)

새 폴더 생성

<div class="modal fade" id="modalForm" tabindex="-1" aria-hidden="true">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h3 class="modal-title">새 폴더 생성</h3>
        <button type="button" class="modal-close-btn" data-bs-dismiss="modal" aria-label="Close">
          <svg xmlns="http://www.w3.org/2000/svg" fill="none" viewBox="0 0 24 24" stroke="currentColor" stroke-width="2">
            <path stroke-linecap="round" stroke-linejoin="round" d="M6 18L18 6M6 6l12 12" />
          </svg>
        </button>
      </div>
      <div class="modal-body">
        <div class="form_group">
          <label class="form_label">폴더 이름</label>
          <input type="text" class="input_field" placeholder="새로운 폴더명을 입력하세요">
        </div>
      </div>
      <div class="modal-footer">
        <button type="button" class="btn outline md" data-bs-dismiss="modal">취소</button>
        <button type="button" class="btn primary md" data-bs-dismiss="modal">생성하기</button>
      </div>
    </div>
  </div>
</div>

2.4. Sizes (sm, lg)

작은 모달

내용이 적을 때 사용합니다.

큰 모달

약관 동의 등 내용이 길고 넓은 공간이 필요할 때 사용합니다. 
<!-- modal-dialog 에 modal-sm 또는 modal-lg 클래스 추가 -->
<div class="modal-dialog modal-sm"> ... </div>
<div class="modal-dialog modal-lg"> ... </div>

2.5. Event / Custom (프로모션 팝업)

<!-- modal-dialog 에 modal-custom 클래스 추가 -->
<div class="modal-dialog modal-custom">
  <div class="modal-content">
    <button type="button" class="modal-close-absolute" data-bs-dismiss="modal">...</button>
    
    <div class="modal-body">
      <img src="event-banner.jpg" alt="배너 이미지">
    </div>
    
    <div class="modal-footer">
      <label class="checkbox_wrapper">
        <input type="checkbox" class="checkbox_input">
        <span class="checkbox_label">오늘 하루 열지 않기</span>
      </label>
      <button type="button" class="btn outline sm" data-bs-dismiss="modal">닫기</button>
    </div>
  </div>
</div>

2.6. Positions (위치 조정)

상단 팝업 (기본)

마진(margin)에 의해 상단에 위치하는 기본 구조입니다.

중앙 팝업

화면 정중앙에 위치하도록 Flex 속성이 추가된 구조입니다.

하단 팝업

아래에서 위로 올라오며 하단에 딱 붙는 바텀 시트(Bottom Sheet) 형태입니다. 모바일에서 매우 유용합니다.
<!-- Top (기본) -->
<div class="modal-dialog"> ... </div>

<!-- Center (수직 중앙 정렬) -->
<div class="modal-dialog modal-dialog-centered"> ... </div>

<!-- Bottom (하단 시트 형태) -->
<div class="modal-dialog modal-dialog-bottom"> ... </div>
