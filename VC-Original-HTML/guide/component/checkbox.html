Checkbox

사용자가 여러 개의 옵션 중 다수를 선택하거나 단일 옵션의 활성화(On/Off) 여부를 결정할 때 사용하는 컴포넌트입니다.

1. Overview & Specs

체크박스 컴포넌트의 구성 요소와 클래스 사용법입니다.

Class Description
.checkbox_wrapper체크박스와 라벨을 묶어주는 래퍼 (클릭 영역 확장 및 Flex 정렬)
.checkbox_input실제 <input type="checkbox"> 요소 (기본 스타일 제거 후 커스텀 적용)
.checkbox_label체크박스 우측에 표시되는 텍스트 라벨

2. Basic Usage

2.1. Primary State

라벨과 함께 사용되는 기본 체크박스입니다.

<label class="checkbox_wrapper">
  <input type="checkbox" class="checkbox_input">
  <span class="checkbox_label">이용약관에 동의합니다.</span>
</label>
