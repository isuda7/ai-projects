Accordion

방대한 양의 컨텐츠를 접고 펼칠 수 있도록 하여, 화면의 시각적 복잡도를 줄여주는 컴포넌트입니다.

1. Overview & Specs

Class Description
.accordion 아코디언 전체 래퍼 클래스
.accordion_item 각 개별 아코디언 아이템 블록
.accordion_btn 열고 닫는 토글 버튼 (Bootstrap JS data-bs-toggle="collapse" 사용)
.collapse / .show 본문 숨김/노출을 제어하는 Bootstrap 유틸 클래스
.block, .line_wall 아코디언 디자인 스타일 변형(Variant) 독립 클래스

2. Basic Usage

2.1. Default State (Single Selection)

기본 아코디언은 하나의 항목이 열리면 다른 항목이 닫힙니다. (data-bs-parent 사용)

디자인 시스템은 일관성 있는 사용자 경험을 제공하고, 디자이너와 개발자 간의 협업 효율성을 극대화하기 위한 컴포넌트와 가이드라인의 집합입니다.

특정 프레임워크(React, Vue 등)에 종속되지 않고 어떤 환경에서든 즉시 가져다 사용할 수 있는 가장 근본적이고 가벼운 범용 시스템을 구축하기 위함입니다. 
<div class="accordion" id="accordionDefault">
  <div class="accordion_item">
    <h3 class="accordion_header">
      <button class="accordion_btn" type="button" data-bs-toggle="collapse" data-bs-target="#collapseOne" aria-expanded="true">
        제목 1
      </button>
    </h3>
    <div id="collapseOne" class="collapse show" data-bs-parent="#accordionDefault">
      <div class="accordion_body">내용 1</div>
    </div>
  </div>
</div>

3. Variants & States

3.1. Multiple Selection

data-bs-parent 속성을 제거하면 여러 개를 동시에 열어둘 수 있습니다.

첫 번째 내용입니다.

두 번째 내용입니다. 서로 독립적으로 작동합니다.
<!-- data-bs-parent 속성 제거 -->
<div class="accordion">
  <div class="accordion_item">
    <h3 class="accordion_header">...</h3>
    <div id="multi1" class="collapse">...</div>
  </div>
</div>

3.3. Block Type

신용카드, 카카오페이, 무통장 입금을 지원합니다.

결제 후 7일 이내 전액 환불 가능합니다.
<!-- .block 클래스 추가 -->
<div class="accordion block">
  <div class="accordion_item">...</div>
</div>

3.4. Line Wall Type

새로운 다크모드가 추가되었습니다.

성능 최적화가 이루어졌습니다.
<!-- .line_wall 클래스 추가 -->
<div class="accordion line_wall">
  <div class="accordion_item">...</div>
</div>

3.5. Complex Title Type

8월 15일 새벽 2시부터 서버 점검이 있습니다.
<button class="accordion_btn collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#complex1">
  <div class="d-flex align-items-center gap-2">
    <span class="badge primary">공지</span>
    <span>시스템 점검 안내</span>
  </div>
</button>
