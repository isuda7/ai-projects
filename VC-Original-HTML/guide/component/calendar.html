Calendar & Scheduler

폼(Form)에서 입력용으로 쓰는 Datepicker(Flatpickr)와, 구글 캘린더처럼 화면 가득 띄우는 스케줄러(FullCalendar)를 분리하여 제공합니다.

1. Datepicker (Flatpickr)

입력창에 날짜나 시간을 입력받을 때 사용합니다. Vibe 테마가 적용되어 있습니다.

1.1. Basic Popup & Range

<!-- HTML -->
<div style="width: 250px;">
  <label class="form-label">단일 날짜 선택 (Basic)</label>
  <input type="text" class="form-control datepicker popup-calendar" placeholder="YYYY-MM-DD">
</div>

<div style="width: 250px;">
  <label class="form-label">기간 선택 (Range)</label>
  <input type="text" class="form-control datepicker range-calendar" placeholder="Select date range">
</div>

<!-- JS -->
<script>
// 1. 달력 초기화
flatpickr(".popup-calendar", { dateFormat: "Y-m-d" });
flatpickr(".range-calendar", { mode: "range", dateFormat: "Y-m-d" });

// 2. 스크롤 분리 현상 방지 (화면 내 스크롤 시 위치 재계산)
window.addEventListener('scroll', function() {
  document.querySelectorAll('.datepicker').forEach(function(input) {
    if (input._flatpickr && input._flatpickr.isOpen) {
      input._flatpickr._positionCalendar();
    }
  });
}, true);
</script>

1.2. Extended Usage (시간, 다중, 제한)

2. Scheduler (FullCalendar)

회의실 예약, 개인 연차, 프로젝트 일정 등 복잡한 스케줄을 그리드 형태로 보여주는 대형 달력입니다.

2.1. Month View (월간 일정표)

<!-- HTML -->
<div id="scheduler-calendar"></div>

<!-- JS -->
<script src='https://cdn.jsdelivr.net/npm/fullcalendar@6.1.10/index.global.min.js'></script>
<script>
document.addEventListener('DOMContentLoaded', function() {
  var calendarEl = document.getElementById('scheduler-calendar');
  var calendar = new FullCalendar.Calendar(calendarEl, {
    initialView: 'dayGridMonth',
    headerToolbar: {
      left: 'prev,next today',
      center: 'title',
      right: 'dayGridMonth,timeGridWeek,timeGridDay'
    },
    events: [ { title: '회의', start: '2026-10-10' } ]
  });
  calendar.render();
});
</script>
