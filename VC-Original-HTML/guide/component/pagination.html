Pagination

긴 목록의 데이터를 여러 페이지로 나누어 탐색할 수 있도록 돕는 네비게이션 컴포넌트입니다.

1. Overview & Specs

Class Description
.pagination페이지네이션 전체를 감싸는 리스트 컨테이너 (ul)
.pagination_item각 개별 리스트 아이템 (li)
.pagination_link, .pagination_btn실제 클릭 영역(a, button)
.active현재 페이지 표시 (링크에 적용)
.disabled이전/다음 버튼 비활성화 시 사용
.pagination_ellipsis건너뛰기(...) 표시용 텍스트

2. Basic Usage

2.1. Primary State

가장 일반적인 형태의 숫자 페이징입니다.

  • «

  • » 
<ul class="pagination">
  <li class="pagination_item"><a class="pagination_link disabled">&laquo;</a></li>
  <li class="pagination_item"><a class="pagination_link active">1</a></li>
  <li class="pagination_item"><span class="pagination_ellipsis">&hellip;</span></li>
</ul>
