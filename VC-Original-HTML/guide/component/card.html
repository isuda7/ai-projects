Card

콘텐츠를 그룹화하여 깔끔한 컨테이너 안에 시각적으로 묶어주는 기본 레이아웃 컴포넌트입니다.

1. Overview & Specs

카드의 영역별(Header, Body, Footer) 뼈대 클래스입니다.

Class Description
.card카드 최상위 컨테이너 (테두리, 그림자, 라운드)
.card_header카드의 상단 영역 (패딩 및 하단 테두리)
.card_title카드 헤더 내부의 메인 제목 텍스트
.card_description카드 헤더 내부의 보조 설명 텍스트
.card_body카드의 메인 콘텐츠 영역 (상하좌우 여백)
.card_footer카드의 하단 액션 영역 (배경색 구분 및 상단 테두리)

2. Basic Usage

2.1. Basic Link Card

버튼 없이 카드 래퍼(Wrapper) 자체가 클릭 가능한 링크(<a>) 형태인 가장 기본 사양입니다. 마우스를 올렸을 때 호버 효과가 포함됩니다.

프로젝트 대시보드

팀의 진행 상황을 한눈에 파악하세요.

최근 완료된 작업 내역과 앞으로 진행해야 할 주요 마일스톤을 확인하고 관리할 수 있습니다.

 
<a href="#" class="card card_interactive">
  <div class="card_header">
    <h3 class="card_title">프로젝트 대시보드</h3>
    <p class="card_description">팀의 진행 상황을 파악하세요.</p>
  </div>
  <div class="card_body">
    <p>본문 내용이 들어가는 영역입니다.</p>
  </div>
</a>

3. Variants & States

3.1. Basic (텍스트 전용 기본형)

별도의 버튼 없이 카드 영역 전체가 클릭 가능한 링크(<a>)로 동작하는 가장 기본적인 형태입니다.

계정 및 보안

비밀번호 변경 및 2단계 인증 설정

최근 로그인 기록을 확인하고, 내 계정을 더 안전하게 보호할 수 있는 보안 옵션을 점검해보세요.

3.2. With Image (세로형)

상단에 썸네일 이미지가 들어가는 일반적인 블로그/상품 카드입니다.

Design

프리미엄 워크스페이스
