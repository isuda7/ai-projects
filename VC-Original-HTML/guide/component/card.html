Card

콘텐츠를 그룹화하여 깔끔한 컨테이너 안에 시각적으로 묶어주는 기본 레이아웃 컴포넌트입니다.

1. Overview & Specs

카드의 영역별(Header, Body, Footer) 뼈대 클래스입니다.

Class Description
.card카드 최상위 컨테이너 (테두리, 그림자, 라운드)
.card_header카드의 상단 영역 (패딩 및 하단 테두리)
.card_title카드 헤더 내부의 메인 제목 텍스트
.card_description카드 헤더 내부의 보조 설명 텍스트
.card_body카드의 메인 콘텐츠 영역 (상하좌우 여백)
.card_footer카드의 하단 액션 영역 (배경색 구분 및 상단 테두리)

2. Basic Usage

2.1. Primary State

헤더, 본문, 푸터를 모두 포함한 기본적인 형태입니다.

프로젝트 설정

이 프로젝트의 기본 정보를 변경합니다.

본문 내용이 들어가는 영역입니다. 각종 폼(Form) 요소를 배치하거나 텍스트를 넣을 수 있습니다.

<div class="card">
  <div class="card_header">
    <h3 class="card_title">프로젝트 설정</h3>
    <p class="card_description">이 프로젝트의 기본 정보를 변경합니다.</p>
  </div>
  <div class="card_body">
    <p>본문 내용이 들어가는 영역입니다.</p>
  </div>
  <div class="card_footer justify-content-end">
    <button type="button" class="btn primary sm">저장하기</button>
  </div>
</div>
