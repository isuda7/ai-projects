Badge

상태, 태그, 카테고리 등을 강조하여 시각적으로 표시하는 작은 레이블 컴포넌트입니다.

1. Overview & Specs

뱃지의 핵심 클래스와 기본 사용법입니다.

Class Description
.badge뱃지 공통 뼈대 (필수 적용)
.badge_primary, .badge_success 등의미적 색상을 띈 부드러운 배경색(Soft) 배지
.badge_solid_primary 등진한 배경색을 띈 솔리드 배지
.badge_outline배경 없이 테두리만 있는 배지
