Textarea

사용자로부터 장문의 텍스트 데이터를 입력받는 폼 컴포넌트입니다.

1. Overview & Specs

ClassDescription
.textarea_fieldTextarea 기본 뼈대
.textarea_wrapper에러 메시지나 버튼 등을 포함하기 위한 래퍼
.textarea_bottom하단 여백 및 정렬 레이아웃 래퍼
.textarea_counter글자 수 카운터 표시 텍스트

2. Basic Usage

2.1. Default State

<textarea class="textarea_field" placeholder="내용을 자세히 입력해주세요."></textarea>

3. Variants & States

3.1. With Character Counter (Outside)

0 / 500 
<div class="textarea_wrapper">
  <textarea class="textarea_field" placeholder="상세 내용을 입력해주세요. (최대 500자)" maxlength="500"></textarea>
  <div class="textarea_bottom">
    <span class="textarea_counter"><span class="current">0</span> / 500</span>
  </div>
</div>
