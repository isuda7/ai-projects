Tabs

동일한 맥락 안에서 여러 뷰(View)를 전환할 때 사용하는 네비게이션 컴포넌트입니다.

1. Overview & Specs

JS 모듈과 연동하기 위해 특정 데이터 속성(data-bs-toggle)을 사용합니다.

Class / Attribute Description
.tabs_wrapper탭 영역 전체를 감싸는 래퍼
.tabs_list탭 버튼들이 나열되는 메뉴 영역 (ul)
.tab_btn개별 탭 버튼 (활성화 시 .active 추가)
.tab-content, .tab-pane부트스트랩 JS 연동을 위한 본문 컨텐츠 클래스
data-bs-toggle="tab"JS 이벤트 바인딩을 위한 필수 속성

2. Basic Usage

2.1. Primary State

가장 널리 쓰이는 밑줄(Underline) 형태의 탭입니다. 클릭하면 내용이 즉시 전환됩니다.

계정 정보 탭의 내용이 노출됩니다.

보안 설정 탭의 내용이 노출됩니다. (비밀번호 변경 등)

알림 탭의 내용이 노출됩니다.

<!-- 구조 축약 -->
<ul class="tabs_list">
  <li class="tab_item">
    <button class="tab_btn active" data-bs-toggle="tab" data-bs-target="#tab1">계정 정보</button>
  </li>
</ul>
<div class="tab-content">
  <div class="tab-pane fade show active" id="tab1">...</div>
</div>
