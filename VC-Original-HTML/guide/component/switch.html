Switch

즉각적인 설정의 켜짐(On)과 꺼짐(Off) 상태를 제어할 때 사용하는 토글 컴포넌트입니다.

1. Overview & Specs

ClassDescription
.switchinput, slider, label을 감싸는 전체 래퍼 (<label>)
.switch_input실제 체크박스 Input (opacity: 0으로 숨김)
.switch_slider가상 요소를 활용해 시각적으로 스위치를 그려주는 요소
.switch_label스위치 옆에 표시되는 설명 텍스트

2. Basic Usage

2.1. Default State

<label class="switch">
  <input type="checkbox" class="switch_input">
  <span class="switch_slider"></span>
  <span class="switch_label">비행기 모드</span>
</label>

3. Variants & States

3.1. Disabled Form

<label class="switch">
  <input type="checkbox" class="switch_input">
  <span class="switch_slider"></span>
  <span class="switch_label">비행기 모드</span>
</label>
