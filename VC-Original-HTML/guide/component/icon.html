Icon

아이콘을 표시하는 기본 컴포넌트입니다. 상세 규격은 추후 작성됩니다.

1. Overview & Specs

Class Description
.icon 아이콘 기본 래퍼 (기본 24x24)
.icon-{size} 사이즈 모디파이어 (12, 16, 20, 24, 28, 32)
.icon-hover-group 형태가 변하는 롤호버를 감싸는 부모 래퍼 클래스
.icon-normal 롤호버 전 나타나는 기본 아이콘
.icon-hover 롤호버 시 나타나는 대체 아이콘

1.1 SVG Sprite 동작 원리 (Master File)

  • 자동 병합 구조: 개발자가 개별 SVG 파일을 추가하면 빌드 시스템이 단일 파일(sprite.svg)로 스캔 및 컴파일합니다.
  • 통신 최적화: 최초 1회 로딩 후 브라우저에 캐싱되어 다수의 아이콘 통신 비용이 발생하지 않습니다.
  • HTML 간소화: 복잡한 벡터 코드 대신 짧은 <use href="..."> 구문만으로 화면에 렌더링됩니다.
  • 완벽한 CSS 제어: currentColor 속성을 통해 CSS 색상(color)을 상속받아 롤호버 시 깜빡임 없이 부드럽게 전환됩니다.
<!-- [원본 관리 경로] 개별 SVG 파일 저장 위치: /assets/icons/src/ -->
<!-- [시스템 출력 경로] 빌드 시스템 병합 결과: /assets/icons/sprite.svg -->
<svg xmlns="http://www.w3.org/2000/svg" style="display: none;">
  
  <!-- 개별 원본 SVG 파일들은 빌드 시 <symbol> 태그로 변환되며 고유 ID가 부여됩니다. -->
  <!-- stroke="currentColor" 속성 덕분에 HTML/CSS에서 부여한 글자색상을 100% 흡수합니다. -->
  <symbol id="icon-search" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" ...>
    <circle cx="11" cy="11" r="8"></circle>
    <line x1="21" y1="21" x2="16.65" y2="16.65"></line>
  </symbol>
  
  <!-- 새로운 아이콘이 필요하면 원본 관리 경로(/assets/icons/src/)에 svg 파일만 추가하면 됩니다. -->
</svg>

1.2 빌드 실행 방법 (How to Build)

현재 정적 HTML 환경에서는 새로운 SVG 파일을 src 폴더에 추가할 때마다 아래 명령어를 수동으로 실행하여 빌드해 주시면 됩니다.

node scripts/build-icons.js
[실행 결과]
🔄 SVG 아이콘 빌드를 시작합니다...
  ✓ 추가됨: icon-search
  ✓ 추가됨: icon-new-icon
🎉 성공! 총 O개의 아이콘이 하나의 sprite.svg로 빌드되었습니다.

2. Basic Usage (SVG Sprite)

2.1 Standard Color Hover

마우스 호버 시 CSS color 값만 부드럽게 변환되는 기본 유형입니다. (순수 CSS :hover 제어) 

<style>
  .demo-color-icon { color: var(--color-gray-500, #6b7280); cursor: pointer; }
  .demo-color-icon.primary:hover { color: var(--color-primary-600, #2563eb); }
  .demo-color-icon.danger:hover { color: var(--color-danger-500, #ef4444); }
</style>

<span class="icon demo-color-icon primary">
  <svg><use href="/assets/icons/sprite.svg#icon-search"></use></svg>
</span>

<span class="icon demo-color-icon danger">
  <svg><use href="/assets/icons/sprite.svg#icon-trash"></use></svg>
</span>

2.3 Shape-Shift Hover

네트워크 깜빡임 없이 호버 시 형태가 완전히 전환되는 롤호버 유형입니다.

<button type="button" class="btn ghost icon icon-hover-group">
  <span class="icon icon-normal">
    <svg><use href="/assets/icons/sprite.svg#icon-heart-outline"></use></svg>
  </span>
  <span class="icon icon-hover text-danger">
    <svg><use href="/assets/icons/sprite.svg#icon-heart-solid"></use></svg>
  </span>
</button>
