Table

다량의 데이터를 행(Row)과 열(Column)로 정렬하여 가독성 있게 보여주는 컴포넌트입니다.

1. Overview & Specs

Class Description
.table_wrapper가로 스크롤을 지원하고 테두리를 그려주는 테이블 감싸개
.data_table실제 <table> 요소에 부여하는 공통 클래스
.is_hoverable행에 마우스를 올렸을 때 배경색 변화 활성화
.is_striped홀/짝수 행마다 배경색을 교차로 적용 (Zebra 표)
