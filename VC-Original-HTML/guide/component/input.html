Input

사용자로부터 짧은 텍스트나 데이터를 입력받는 가장 기본적인 폼(Form) 컴포넌트입니다.

1. Overview & Specs

텍스트 입력 필드의 핵심 클래스와 기본 사용법입니다.

Class Description
.input_fieldInput 공통 뼈대 (필수 적용)
.size_sm, .size_md, .size_lg물리적인 폼 높이 지정 (기본은 md)
.is_error유효성 검사 실패 시 에러 상태 (적색 테두리)
.full_width부모 요소의 100% 너비 차지 (.input_wrapper에 적용)
.has_left_icon, .has_right_icon아이콘 공간 확보를 위한 패딩 처리
