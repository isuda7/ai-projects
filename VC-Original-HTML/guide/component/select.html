Select

사용자에게 여러 옵션 중 하나를 선택할 수 있도록 제공하는 드롭다운 형태의 폼 컴포넌트입니다.

1. Overview & Specs

네이티브 <select> 태그에 브라우저 기본 스타일을 초기화하고 디자인 시스템 스타일을 입힙니다.

Class Description
.select_fieldSelect 공통 뼈대 (화살표 커스텀 포함, 필수 적용)
.sm, .md, .lg물리적인 폼 높이 지정 (기본은 md)
.is_error유효성 검사 실패 시 에러 상태 (적색 테두리)

2. Basic Usage

2.1. Primary State

기본 셀렉트 박스입니다.

<select class="select_field md">
  <option value="" disabled selected>옵션을 선택하세요</option>
  <option value="1">옵션 1</option>
  <option value="2">옵션 2</option>
</select>
