Skeleton

데이터가 로딩되는 동안 공간을 임시로 채워 보여주는 뼈대 UI입니다.

1. Overview & Specs

ClassDescription
.skeleton스켈레톤 기본 요소 (Shimmer 효과 포함)
.circle, .title, .text형태 모듈 (원형, 타이틀형, 텍스트 줄형)

2. Basic Usage

2.1. Default State

<div class="skeleton" style="width: 250px; height: 100px;"></div>

3. Variants & States

3.1. Card Skeleton

<div style="width: 320px; padding: 24px; border-radius: 12px; ...">
  <div class="skeleton" style="height: 160px; margin-bottom: 24px;"></div>
  <div class="skeleton title" style="width: 70%; margin-bottom: 16px;"></div>
  <div class="skeleton text" style="margin-bottom: 12px;"></div>
  <div class="skeleton text" style="width: 40%;"></div>
</div>
