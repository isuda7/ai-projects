Utilities Foundation

여백, 정렬, 디스플레이 등 레이아웃을 구성할 때 사용하는 최소한의 공통 커스텀 유틸리티 클래스 가이드입니다.
(본 프로젝트는 외부 CSS 프레임워크와의 충돌을 피하기 위해 Bootstrap 등을 배제하고, 프로젝트 전용으로 작성된 직관적인 커스텀 클래스만을 사용합니다.)

Spacing (여백)

Margin(m)과 Padding(p)을 사용하여 요소 간의 간격을 조정합니다.

Class Prefix Description Example
m-*, p-* 모든 방향 (All sides) m-2, p-4
mx-*, px-* 가로 방향 (Left & Right) mx-auto, px-3
my-*, py-* 세로 방향 (Top & Bottom) my-2, py-5
mt-*, pt-* 상단 (Top) mt-4, pt-1
mb-*, pb-* 하단 (Bottom) mb-3, pb-0

Spacing Scale (크기 기준)

숫자(0~5)는 기본 변수(Spacer: 16px)를 기준으로 곱해진 직관적인 픽셀(px) 수치를 의미합니다.

Scale Number Calculated Size (px) Description
0 0px 여백 없음
1 4px 매우 좁은 간격 (0.25rem)
2 8px 좁은 간격 (0.5rem)
3 16px 기본 간격 (1rem)
4 24px 넓은 간격 (1.5rem)
5 48px 아주 넓은 간격 (3rem)
auto auto 브라우저 자동 계산 (주로 중앙 정렬시 사용, 예: mx-auto)

Flexbox

요소의 배치와 정렬을 위해 Flexbox 유틸리티를 활용합니다.

Class Description
d-flex display: flex; 적용
flex-column 세로 방향 정렬 (flex-direction: column;)
justify-content-center 가로 중앙 정렬
align-items-center 세로 중앙 정렬
gap-* Flex 아이템 간의 간격 설정 (예: gap-3)

Text & Typography

Class Description
text-center 텍스트 가운데 정렬
text-start, text-end 텍스트 좌/우측 정렬
fw-bold, fw-normal 텍스트 굵기 조절
