# 📚 가이드 시스템 설계 및 아키텍처 컨텍스트 (Guide System Architecture)

이 문서는 프로젝트의 가이드 영역(`/guide`) 및 퍼블리싱 대시보드에 대한 **구조적/시각적 설계 기준**을 정의합니다. AI가 가이드 화면이나 컴포넌트를 작업할 때 임의로 레이아웃을 생성하지 않도록 돕는 핵심 지침서입니다.

## 1. 📝 화면 생성 원칙 (MD 프롬프트 기반)
가이드 및 대시보드 내의 어떠한 화면도 AI가 임의의 형태로 구성해서는 안 됩니다.
반드시 사전에 정의된 **유형별 프롬프트 가이드 문서(.md)**를 통해 마크업과 컴포넌트 구조를 생성해야 합니다.
*   대시보드 화면 생성/수정: `template/PROMPT_DASHBOARD.md` 참조
*   신규 UI 컴포넌트 가이드 생성: `template/PROMPT_GUIDE_BASE.md` (표준 양식) 참조
*   가이드 유형별 생성/수정: `PROMPT_GUIDE_*.md` (_02 번 부터 파일 순서대로 메뉴 추가) 참조

## 2. 📂 가이드와 사용자(Front) 영역의 폴더/라우팅 분리
*   **사용자 화면**: `src/pages/beforeLogin/` (로그인 전), `src/pages/afterLogin/` (로그인 후) 또는 일반 `src/pages/` 하위에 위치하며, 전역 레이아웃인 `Layout` 컴포넌트(`src/components/layout/layout.tsx`)를 사용합니다.
*   **가이드 화면**: 모든 문서는 `src/pages/guide/` 폴더 하위에 위치해야 하며, 반드시 `guide-layout.tsx`로 감싸져(Wrapping) 독립된 도메인으로 작동해야 합니다.

## 3. 🧩 공통 컴포넌트 정책 (Header / Footer / Layout)
*   **사용자 화면과 가이드 화면은 모든 레이아웃을 공통으로 사용하지 않습니다.** (완벽 분리)
*   **로고 텍스트 이원화**: 대시보드(index.html) 화면의 좌측 상단 로고는 **`Dashboard`**로 노출하고, 가이드 하위 문서들(guide/*)의 로고는 **`Design System`**으로 분리하여 노출합니다.
*   **Header Active 스타일**: 헤더 메뉴 텍스트는 `14px`, 굵은 폰트(Semi-bold), 어두운 회색(`#6b7280`)으로 구성하고 마우스 오버 시 진해져야 합니다. 현재 접속 중인 메뉴는 포인트 컬러(Sky Blue: `#0294de`)를 적용하고 메뉴 텍스트 바로 하단에 밑줄(인디케이터)이 그어지는 Active 처리를 완벽하게 구현해야 합니다.

> **⚠️ [전역 정책] 프리뷰 개방형(Open-Rendering) 원칙**
> 컴포넌트 가이드의 프리뷰 영역은 사용자 화면이 브라우저에 렌더링되는 자연스러운 상태를 그대로 시뮬레이션해야 합니다. 따라서 어떠한 경우에도 컴포넌트를 Card나 별도의 테두리(Border), 배경색(Background)을 가진 컨테이너로 억지로 감싸서 렌더링해서는 안 됩니다.

## 4. 📐 가이드 내부 레이아웃의 이원화 정책
가이드 레이아웃은 페이지 목적에 따라 2가지 레이아웃 규칙을 따릅니다.

### A. 퍼블리싱 대시보드 모드 (`index.html`)
*   **목적**: 화면 개발 진척도, 경로, URL을 표 형태로 한눈에 관리하는 메인 화면.
*   **레이아웃 특징**: 테이블에 많은 데이터가 들어가야 하므로 좌측 사이드바 메뉴를 배치하지 않으며, **브라우저의 전체 가로 너비(100%)를 시원하게 사용**합니다. (특정 너비로 제한하지 않음)
*   **공통 페이지 카테고리 필수 포함**: 대시보드 목록에는 반드시 '공통' 분류 아래 404 및 500 에러 페이지가 필수 페이지로 등록되어야 합니다.

### B. 디자인 시스템 가이드 문서 모드 (`guide/` 하위 파일들)
*   **목적**: 버튼, 컬러 등 디자인 시스템 스펙과 컴포넌트 사용법을 열람하는 화면.
*   **레이아웃 특징**: 가독성을 위해 **좌측에 사이드바(Guide Menu)를 노출**하고, 우측 본문 영역은 화면을 꽉 채우지 않고 가운데 정렬된 제한된 너비(`max-width: 1024px`)를 갖도록 구성합니다.
*   **자연스러운 스크롤**: 가이드 템플릿의 전체 높이는 절대 `height: 100vh` 및 `overflow: hidden`으로 억지로 묶지 말고, 컨텐츠 길이에 따라 자연스럽게 브라우저 스크롤이 생기도록 구성해야 합니다.

## 5. 🎨 디자인 컨셉 지향점
모든 가이드 및 사용자 화면은 화려함보다는 정보 전달력이 뛰어난 **'Professional Modern'** 스타일을 지향합니다.
*   **여백과 단위**: 모든 단위는 `rem` 대신 직관적인 **`px` 단위로 통일**하여 소통 오류를 줄입니다.
